PRIME GADGET WEBSITE - CODE FILES

index.html   the page structure (header, home sections, category/cart/search pages, footer)
styles.css   all colours, layout and phone/desktop sizing
script.js    products, prices, search, cart and WhatsApp checkout
images/      every product photo and the logo

COMMON EDITS (all in script.js)
- Change a price: find the product name, change "price": 22000 (no commas).
- Add a product: copy one product line in the `stock` list, change name, cat, price and img.
  Put its photo in images/ and add it to the IMG list at the top of script.js.
- WhatsApp number: const WHATSAPP = "2349118153035"
- Home page products: featuredNames, bestNames and dealName.

TO PUT ONLINE: upload this whole folder (or a zip of it) to app.netlify.com/drop.
All four items (index.html, styles.css, script.js, images/) must stay together.
